# `/obs` Mod (TypeScript plugin) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Claude Code plugin `trajviz-obs`: a hooks module that registers `/obs`, runs the Python bridge, keeps snapshots in `$.state`, draws the overview card and the live pane, serves the `obs` tool to the model, and ships as an installable marketplace repository with README and docs.

**Architecture:** `hooks/register.tsx` only wires events to functions in `hooks/lib/*` (pure helpers and `$`-callers), `hooks/commands/*` (one handler per subcommand group returning `CommandRunResult`) and `hooks/render/*` (trees). All data comes from the bridge through `runBridge()`; the mod never parses transcripts. Snapshots are immutable per card (a state family keyed by snapshot id) with `latest` for the pane and status line.

**Tech Stack:** Claude Code 2.1.304 hooks-module API (`claude-code` types, JSX with `h`), TypeScript 5.9 (type-check only), `claude plugin validate/test`; the bridge from `docs/superpowers/plans/2026-10-22-obs-bridge.md`.

**Spec:** `docs/superpowers/specs/2026-10-22-obs-plugin-design.md`

## Global Constraints

- Plugin name `trajviz-obs`; command `obs` registered with `description: "Visualize and diagnose this session's trajectory with TrajViz"`, `argumentHint: "[overview|pane|report|dashboard|issues|health|analyze|fixes|json|help] [--session id]"`, `immediate: true`; tool `obs` registered deferred (`isDeferred: true`).
- `$.env.get("…")` names and every `$.state` reference are literals in source; no helper takes an env name or a state key; every plugin file is reached by a static `import` (no `import()`); `$.clock.sleep` is never used (budget), waits use `$.clock.after` and timestamps.
- Every `$.process.run` passes `timeoutMs`: 120 000 for snapshot, resolve, sessions, view, brief, doctor; 600 000 for json, report, bundle, compare, scorecard, converge-cli, collect, schemas, labels; `$.process.spawn` for setup, extras, label runs and dashboards.
- The bridge is `[python, "-I", `${$.plugin.root}/bridge/trajviz_obs_cli.py`, ...argv]` with `cwd` = `await $.session.cwd()`; `python` is the managed venv's interpreter (`<cache>/trajviz-obs/venv/bin/python`, `Scripts\python.exe` on Windows).
- Artifacts folder passed as `--artifacts <cache>/trajviz-obs/sessions/<session-id>`; `<cache>` = `XDG_CACHE_HOME`, else `HOME/.cache`, else `LOCALAPPDATA` when `OS === "Windows_NT"`.
- Transcript path: the latest `classic.SessionStart`/`classic.Stop`/`classic.UserPromptSubmit` `transcript_path`, else `<configDir>/projects/<slug>/<id>.jsonl` if it exists, else the bridge's `resolve --session-id`.
- Card buttons only when `e.viewport?.isFullscreen === true` or `e.surface !== "terminal"`; otherwise a dim line of `/obs` forms. Breakpoints by `e.viewport.columns`: ≥ 100 full; 72–99 reduced; < 72 minimal (no Raster). Pane: tabs `1`–`7`, `r`, `w`, `o`, `d`; auto-open only when `presentation.isFullscreen && presentation.columns >= 140` with `columns: 56`; `/obs pane` opens anywhere (`rows: 14`).
- `Raster` only when `e.surface === "terminal"`; other surfaces get text sparklines and `Markdown` tables.
- LLM: `analysisModel` default `sonnet`, `labelModel` default `haiku`, `"session"` means `await $.session.model()`; `maxTokens`/`timeoutMs` from each prompt's `max_tokens`/`timeout_s`; plan line printed first; `$.ui.ask` when calls > 4 and interactive (a rejection is no); headless proceeds up to `labelMaxSteps`; usage summed and printed.
- No browser open when `SSH_CONNECTION` or `SSH_TTY` is set or `openBrowser` is false; paths and URLs always printed.
- Row texts for error states are the spec's "Error and degraded states" table, verbatim.
- userConfig fields exactly as the spec's table (types, titles, defaults); none required or sensitive; `author` set so `claude plugin validate --strict` passes.

## Review Focus

- `/obs` typed before the environment exists on a machine with only Python 3.9 and no `uv`: the row names what was looked for and how to fix it, nothing hangs (Task 3).
- A second `/obs` while the first is still computing: one line saying an analysis is in progress, no second process (Task 5).
- A card from an earlier `/obs` after three refreshes: still shows its own numbers (Task 7).
- `/obs analyze` headless with the plan over 4 calls: proceeds without asking; interactive dismissal: cancelled with no model call (Task 12).
- The dashboard child when the port is busy: the row carries the child's first stderr line and no dangling loop stays registered (Task 11).
